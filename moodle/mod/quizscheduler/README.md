# Quiz Scheduler Plugin for Moodle

Plugin de Agendamento de Questionários para Moodle que permite que os alunos agendem horários específicos para realizar questionários.

## Características

- Agendamento de horários para questionários
- Controle automático de acesso baseado no horário agendado
- Relatórios de progresso e desempenho
- Interface em português brasileiro e inglês
- Conformidade com GDPR
- Limpeza automática de dados expirados

## Requisitos

- Moodle 4.5+
- PHP 8.1+
- Mod Quiz instalado

## Instalação

1. Faça o download ou clone este repositório
2. Copie a pasta `quizscheduler` para o diretório `/mod/` do seu Moodle
3. Acesse a administração do Moodle como administrador
4. Complete o processo de instalação através da interface web
